# Git 끝말잇기 게임

끝말잇기를 하며 Git의 Pull과 Push를 연습합니다.

## 게임 규칙

- 마지막 단어의 끝 글자로 시작하는 단어를 이어갑니다.
- 사전에 있는 단어만 사용하고, 같은 단어는 반복할 수 없습니다.
- 커밋 메시지에는 새로 추가한 단어만 적습니다.

## 진행 방법

### 1. 저장소 복제하기

Antigravity에서 새 창을 열고 **Clone Repository**를 클릭합니다.

아래 주소를 입력하고 저장할 폴더를 선택한 뒤, 복제가 끝나면 **Open**을 클릭합니다.

```text
https://github.com/Kiboom/WordRelay
```

### 2. 팀 브랜치로 이동하기

AI에게 요청합니다.

> `[팀 브랜치 이름]` 브랜치로 이동해줘.

### 3. 최신 내용 받아오기

매 차례 작업을 시작하기 전에 AI에게 요청합니다.

> 우리 팀 브랜치의 최신 내용을 받아줘.

### 4. 단어 추가하기

`words.txt`의 마지막 단어를 확인하고, 이어지는 단어를 한 줄에 추가합니다.

```text
사과
과일
일기
```

### 5. 커밋하고 Push하기

AI에게 요청합니다.

> 추가한 단어를 커밋 메시지로 사용해서 커밋하고 팀 브랜치에 Push해줘.

팀원들은 차례대로 **최신 내용 받아오기 → 단어 추가 → Push**를 반복합니다.

### Push가 거절되거나 충돌이 생기면

다른 팀원이 먼저 Push했을 수 있습니다. AI에게 요청합니다.

> 최신 내용을 받아 충돌을 해결해줘. 내 단어가 이어지면 Push하고, 아니면 알려줘.

단어가 이어지지 않으면 새 단어를 정하고 다시 Push합니다.
